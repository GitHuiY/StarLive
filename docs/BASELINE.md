### 存储与模拟值

- `localStorage` 键为 `seven-stars-v2`，数据包含 `weeks`、`drafts`、`demo`、`settings`。
- 周键按本地周一日期保存，例如 `2026-11-2`；每周七个数组，事项字段为 `id`、`name`、`category`、`done`。
- 连续提醒演示默认 45 分钟、范围 15–90 分钟；累计演示默认 180 分钟、范围 30–360 分钟。**正式需求已改为连续 60 分钟、单应用每日 60 分钟、所选应用合计每日 180 分钟。**
- 固定模拟值：抖音 52 分钟、小红书 36 分钟、微信 24 分钟、哔哩哔哩 16 分钟；页面总量 128 分钟，默认选择前两个应用后摘要为 88 分钟。
- “稍后”目前仅关闭演示对话框并显示提示，不存在延后调度。
- 浏览器清理网站数据会清除记录；尚无导入、导出、原生持久化或备份。

## 本次实际验证

### 方法

1. 阅读 README、MIT LICENSE 及三个 `dist` 源文件，核对 Git 提交与初始工作区。
2. 执行 `node --check dist/app.js`，退出码 0。
3. 使用仅监听 `127.0.0.1` 的临时静态 HTTP 服务检查真实资源响应。
4. 使用本机已有 Microsoft Edge 的独立临时配置，通过浏览器调试协议驱动 DOM 事件；未安装 Playwright、Puppeteer 或其他依赖，也未接触用户日常浏览器配置。
5. 使用合成计划内容，检查本地存储、路由、星光数值、对话框及页面宽度，并查看三张截图。浏览器测试时区为 `Asia/Shanghai`。

普通执行环境的首轮 Edge 启动没有返回就绪信号，辅助 CIM 查询也受环境限制；该轮已终止并向主会话报告。随后在授权的执行环境中完成独立本机验证，未涉及手机或网络重连。

### 结果

本机浏览器检查共 **24 项，24 项通过**；这代表当前原型行为符合所检查的基线，并非新需求已实现。

| 检查组 | 结果与证据 |
| --- | --- |
| HTTP 资源 | `/`、`/style.css?v=2`、`/app.js?v=2` 均为 200，内容非空，类型分别为 HTML、CSS、JavaScript |
| 初始星图 | 初始总览、七颗星、示例标识及不含周一至周四连线的路径均通过 |

| 计划与持久化 | 草稿与正式计划隔离；确认后进入个人计划；完成状态重载后保留；未改名重新确认不清空完成状态 |

| 键盘与减少动态 | Enter 选择周四并抵达对应视口，减少动态效果模式可导航 |

### 未覆盖的检查

- 本次浏览器检查主要通过 DOM 事件驱动，不能代替真实触摸、读屏器、字体放大或目标手机完整视觉验收。
- 360／420 CSS 像素宽度检查不是对目标手机 1260×2800 物理屏幕的实测。
- 没有执行跨午夜、跨周、跨月跨年、时区切换和系统时间修改的完整运行时测试；日期刷新问题已由源码确认。
- 未验证存储配额耗尽、损坏数据恢复、备份、升级迁移或 Android Release 构建。
- 页面没有外部请求的观测结论不能替代未来 APK 的网络与隐私检查。
- 手机 ADB 连接、截图或滑动成功不能替代 UsageStats、通知、后台延迟或耗电验收；这些属于阶段 2 及后续真机工作。

## 与已确认正式需求的差距

| 优先项 | 缺口 | 后续验收要求 |
| --- | --- | --- |
| Android 工程 | 基线只有静态网页，没有原生权限、生命周期或构建配置 | 先验证 Android 15 真机能力，再确定正式技术方案 |
| 真实统计 | 固定演示应用与时长，不使用包名，也不读取系统事件 | 明确授权状态、按包名识别应用、统计口径和数据完整性；正式统计不混入模拟值 |
| 三类提醒 | 仅两类演示设置，连续默认仍为 45 分钟 | 实现连续 60 分钟、单应用每日 60 分钟、所选合计每日 180 分钟 |
| 会话 | 没有监测事件或计时引擎 | 切换接续；离开／锁屏 ≤120 秒保持关联且间隔不计，>120 秒重开；跨午夜连续会话接续 |
| 通知策略 | 只有手动对话框，未实现系统通知、去重、合并和稍后调度 | 每会话／每日一次；同时触发合并；稍后 30 分钟且届时仍使用才提醒；关闭监测取消 |
| 日期刷新 | `now`、`today`、`monday`、`weekKey` 在页面加载时固定 | 长时间打开时跨日／跨周更新，跟随系统时区；每日累计按当地日界线切分 |
| 未完成显示 | 原 CSS 主要将“已完成”事项灰化并加删除线 | 按新需求将未完成事项保留原日并灰色呈现，不自动结转 |
| 本地备份 | 尚无导入／导出 | 实现手动本地备份和恢复，校验格式、版本及损坏输入 |
| 后台可靠性 | 没有后台运行或能耗证据 | 目标 vivo 真机验证锁屏、省电、进程终止、重启；记录延迟、遗漏与耗电 |
| 正式交付 | 没有签名、版本或可复现 Android 构建说明 | 最终测试签名 Release 包、覆盖升级、校验和及签名证书指纹；私钥不入库 |

本阶段保留原型交互，不用演示逻辑替代真实统计，也不将尚未完成的 Android 功能写成已验证。
